# 🚀 Databricks Training

## 📖 Description

This repository contains my complete **Databricks Training** assignments, hands-on exercises, and practice work completed during the training program. It covers both **SQL** and **PySpark**, starting from database fundamentals to advanced querying and data processing techniques.

Throughout this training, I worked on real-world scenarios involving relational databases and big data processing using Databricks. The repository is organized week-wise and day-wise, making it easy to navigate through different topics and assignments.
